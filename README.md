# Portfólio — Fê

Site pessoal em construção, atualizado semanalmente. Feito com HTML, CSS e JavaScript puros.

## Estrutura

- `index.html` — estrutura e conteúdo
- `style.css` — estilos (paleta, tipografia, layout, responsividade)
- `script.js` — menu mobile, barra de progresso e animações de entrada
- `favicon.svg` — ícone do site

## Log de progresso

- **v0.1** — estrutura do site e conteúdo inicial no ar
- **v0.2** — estilo base, tipografia e interatividade (menu mobile, barra de progresso, animações de entrada)
- **v0.3** — favicon e meta tags (Open Graph/Twitter Card)
- **v0.4** — remoção da seção de log de progresso da página (mantida aqui no README)
- **v0.5** — melhorias de acessibilidade: skip link, foco visível, aria-labels nos links de contato, navegação do menu por teclado
- **v0.6** — troca de paleta (verde → tons de rosa), ajuste de contraste dos textos e links reais de contato

## Como rodar localmente

Basta abrir o `index.html` no navegador, ou usar uma extensão tipo
"Live Server" no VS Code para recarregar automaticamente durante a edição.
